Ce qu'on emprunte / ce qu'on détourne

  • Emprunté · format vertical 3:4 type packaging, fond mono saturé, rayures, cartouche oblique, typo verticale latérale, grain noise.
  • Détourné · au lieu d'une mascotte, photo réelle dans cadre cream (« vinyl face » → « vinyl portrait »).
  • Limites · l'effet sérigraphie pur (posterize/halftone) demande ImageMagick. Là on simule avec filter: contrast() saturate() + mix-blend-mode. Si tu valides la direction, je peux installer IM via brew install imagemagick pour pousser plus loin (vrai posterize 4-tons + grain print).
  • Format final · pour un blog, je recommande aussi une déclinaison paysage 1200×630 (OG image partage social) — facile à dériver.
