Fichier .env, en clair

Un fichier .env range les clés et réglages sensibles d'un projet hors du code visible.

Relier le sujet aux clés IA et au déploiement sans entrer dans une leçon de programmation.

Exemple concret

Au lieu d'écrire ta clé Anthropic dans un script, tu écris ANTHROPIC_API_KEY=... dans .env puis le script la lit au démarrage.

Pourquoi ça compte

Les agents et automatisations manipulent vite des secrets. Le .env évite de les exposer dans les fichiers partagés.

Tu le croises à la racine d'un projet local, ou sous forme de variables d'environnement dans Vercel, Railway ou Supabase.

À ne pas confondre

Clé API : Une clé API est un mot de passe technique qui autorise un outil à appeler un service d'IA en ton nom.

Variables d'environnement Vercel : Les variables d'environnement Vercel stockent les clés et réglages sensibles côté déploiement.

Erreurs fréquentes

  • Oublier .env dans .gitignore.
  • Partager une capture d'écran avec les vraies valeurs.
  • Modifier une variable sans redémarrer l'outil.
