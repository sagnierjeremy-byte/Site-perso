— Définition

Hook, en clair

Un hook déclenche une action automatique avant ou après certains gestes de l'agent.

Présenter le hook comme un automatisme silencieux : avant un commit, après un tool-use, etc.

Exemple concret

Je branche un hook PostToolUse qui formate le code après chaque édition. Claude ne s'en occupe plus, ça se fait tout seul.

Pourquoi ça compte

Les hooks rendent l'agent fiable. Ils encodent des règles que tu ne veux plus rappeler à la main.

Tu le vois dans Claude Code pour bloquer une commande, lancer un formatage ou vérifier un fichier modifié.

À ne pas confondre

Claude Code : Claude Code est l'agent de Claude qui lit un projet, modifie des fichiers et lance des commandes avec ton accord.

CLAUDE.md : CLAUDE.md est le fichier où tu notes les règles du projet pour que Claude ne reparte pas de zéro.

Erreurs fréquentes

  • Mettre du code lent dans un hook et ralentir chaque action.
  • Oublier qu'un hook peut bloquer une action en retournant une erreur.
  • Stocker des secrets dans un hook au lieu d'un .env.

Mini-checklist

  • Je vérifie d'abord si le mot désigne un concept, un outil, un risque ou une métrique.
  • Je le relie à un cas concret : Je branche un hook PostToolUse qui formate le code après chaque édition. Claude ne s'en occupe plus, ça se fait tout seul.
  • Je garde en tête le piège principal : Mettre du code lent dans un hook et ralentir chaque action.
