— Définition

Sandbox, en clair

Une sandbox isole l'agent pour limiter les dégâts si une action se passe mal.

Présenter la sandbox comme une cage à dégâts limités, pas comme une prison.

Exemple concret

Codex tourne dans un container isolé. Si l'agent fait n'importe quoi, ton ordi reste intact, le container saute.

Pourquoi ça compte

Sans sandbox, un agent qui se trompe peut tout casser sur ta machine. Avec, le pire scénario est un reset.

Tu la vois dans Codex cloud, les agents qui exécutent du code, les tests et les environnements contrôlés.

À ne pas confondre

Permission d'outil : Une permission d'outil décide ce qu'un agent a le droit de lire, écrire ou lancer.

Moindre privilège : Le moindre privilège consiste à donner à l'agent seulement les droits nécessaires.

Erreurs fréquentes

  • Donner accès au système hôte depuis la sandbox.
  • Oublier de couper internet dans la sandbox quand pas nécessaire.
  • Croire qu'une sandbox équivaut à une sécurité totale.

Mini-checklist
