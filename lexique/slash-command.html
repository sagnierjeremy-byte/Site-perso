— Définition

Slash command, en clair

Une slash command est une commande courte qui lance une instruction préparée dans un outil IA.

Présenter le pattern /commande comme un raccourci réutilisable pour les tâches répétitives.

Exemple concret

Je crée /review qui lance une revue de code complète, je tape /review et Claude applique mon process sans le redécrire.

Pourquoi ça compte

Les slash commands transforment un workflow manuel en bouton. Tu gagnes des heures sur les routines.

Tu la croises dans Claude Code, Codex CLI, les commandes /memory, /agents, /review ou les workflows réutilisables.

À ne pas confondre

Claude Code : Claude Code est l'agent de Claude qui lit un projet, modifie des fichiers et lance des commandes avec ton accord.

CLAUDE.md : CLAUDE.md est le fichier où tu notes les règles du projet pour que Claude ne reparte pas de zéro.

Erreurs fréquentes

  • Créer une commande pour un truc qu'on ne fera qu'une fois.
  • Empiler 50 commandes sans en supprimer aucune.
  • Oublier de versionner les commandes dans le repo.

Mini-checklist

  • Je vérifie d'abord si le mot désigne un concept, un outil, un risque ou une métrique.
  • Je le relie à un cas concret : Je crée /review qui lance une revue de code complète, je tape /review et Claude applique mon process sans le redécrire.
  • Je garde en tête le piège principal : Créer une commande pour un truc qu'on ne fera qu'une fois.
