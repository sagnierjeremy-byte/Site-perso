— Installation en 3 minutes · sans toucher au code

Pas dev ?
Tu t'en sors quand même.

Le tunnel a été pensé pour que tu n'aies jamais à ouvrir un fichier de configuration. Stripe → Vercel → 3 clés API collées dans l'UI. Si l'app dit vert, c'est que ça marche.

01

Tu paies sur Stripe

Carte bancaire, 2 minutes. Tu reçois le ZIP + l'invitation au repo GitHub privé par email dans la foulée.

02

Tu deploy sur Vercel

Bouton « Import » sur Vercel, tu pointes ton repo (ou tu drop le ZIP), tu cliques deploy. Plan Hobby gratuit, aucun fichier à éditer.

03

Tu colles 3 clés dans Paramètres

FAL_KEY, OPENROUTER_API_KEY, ADMIN_TOKEN dans le dashboard Vercel. Tu rouvre /settings dans l'app, tu clique « Tester la connexion ». Vert → tu génères ta première photo.

Comment ça marche après l'achat ?
Tu paies sur Stripe (carte bancaire). 2 minutes plus tard, tu reçois un email avec : (1) le bouton de téléchargement du ZIP, (2) l'invitation au repo GitHub privé (si tu as donné ton username au paiement, sinon un lien pour le donner après). Aucune validation manuelle, aucune attente. Tu peux décompresser et lancer npm install && npm run dev dans la foulée.
Et si je suis pas développeur ?
Tu peux quand même t'en sortir avec Claude Code. L'outil est bien commenté, le STORYTELLING.md explique tout, et le CLAUDE.md permet à Claude de répondre à tes questions de modif. Mais sois honnête avec toi-même : si tu ne sais pas ce qu'est une variable d'environnement, prends-toi 1h pour lire mon guide Claude Code avant de précommander.
Je peux modifier le code ?
Oui, complètement. Tu peux fork le repo (l'invitation read-only te permet de fork dans ton compte), tu travailles dans ton coin, tu fais ce que tu veux. Pas de licence virale, pas de partage obligatoire de tes modifs.

Pour 50 photos générées : environ 10 € de crédit fal.ai (à 0,04 € / photo Seedream) + 0,50 € de crédit OpenRouter pour les briefs Gemini. Soit environ 10,50 € au total, après l'achat unique de 99 €. Si tu ajoutes une équipe de 5 collaborateurs (10 photos chacun) : ~5 € supplémentaires.
Pourquoi je devrais te faire confiance ?
Trois raisons : (1) je publie tout sous mon vrai nom à mon vrai email jeremy.sagnier@eurofiscalis.com · pas un alias anonyme. L'invitation au repo GitHub privé te donne accès à toutes les mises à jour que je pousserai dessus, sans frais supplémentaires. Pas de "v2 = repaye 99 €". Le ZIP est figé à la version au moment de ton achat, mais le repo continue de bouger.
